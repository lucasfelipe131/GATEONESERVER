# Fluent8

MVP mobile-first para aprendizagem de idiomas com foco em conversação real.

## Incluído
- Inglês, espanhol e francês
- onboarding por objetivo, nível e tempo diário
- missão diária
- cenários de hotel, aeroporto, restaurante, trabalho, transporte, compras e social
- reconhecimento e síntese de voz pelo navegador
- revisão inteligente e progresso persistido localmente
- índice de fluência por competências
- PWA instalável
- endpoint opcional `/api/coach` preparado para OpenAI via `OPENAI_API_KEY`

## Rodar
`npm start`

Healthcheck: `/health`
